# reports/ — Generated Deal Artifacts (Gitignored)

Evaluation reports, due-diligence checklists, outreach drafts, and LOIs live here.
They are **personal deal data** and are excluded from version control (see
`DATA_CONTRACT.md`).

Naming conventions:

| Pattern | Description |
|---|---|
| `reports/{NNN}-{slug}-{date}.md` | A-F evaluation report |
| `reports/{NNN}-dd-checklist.md` | Due diligence checklist |
| `reports/{NNN}-outreach.md` | Broker/seller outreach draft |
| `reports/{NNN}-loi.md` | Letter of intent draft |

Only `.gitkeep` is tracked so the directory exists in a fresh clone.
