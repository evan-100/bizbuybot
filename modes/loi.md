# `loi.md` — Letter of Intent Generation Mode

> This mode generates a customized Asset Purchase Letter of Intent from `templates/loi-template.md`, filling in deal-specific values from the evaluation report. Output: `reports/{NNN}-loi.md`.

---

## Inputs

- A deal ID (e.g., `003`), OR
- A business slug that matches a report in `reports/`.

---

## Execution Steps

### Step 1 — Locate the Evaluation Report

- If a deal ID is given, read `data/acquisitions.md`, find the row with that ID, and read the `Report` column to get the evaluation report path (e.g., `reports/003-metro-laundromat-2026-08-22.md`).
- If a slug is given, find the report file in `reports/` matching `reports/{NNN}-{slug}-*.md`.
- Read the evaluation report, especially Block E (deal structuring) and the YAML footer (`asking_price`, `sde`, `financing_fit`, `business_name`).

### Step 2 — Read the LOI Template

Read `templates/loi-template.md`. This is the base document with bracketed placeholders.

### Step 3 — Extract Deal Values from the Evaluation Report

Map these values from the evaluation report and the buyer profile:

| Placeholder | Source |
|---|---|
| `[BUYER]` | `config/profile.yml` → `identity.name` |
| `[SELLER]` | Listing (seller/broker name) or "Seller of [BUSINESS]" if unknown |
| `[BUSINESS]` | Evaluation report YAML footer → `business_name` |
| `[DATE]` | Today's date (`YYYY-MM-DD`) |
| `[PURCHASE PRICE]` | Block E target anchor valuation (NOT the asking price — the buyer's opening offer). If Block E does not specify, use the asking price from the YAML footer. |
| `[CASH AT CLOSE]` | Block E capital stack — buyer cash equity (typically 10% of purchase price). |
| `[SELLER NOTE]` | Block E capital stack — seller note amount (typically 10–15% of purchase price). |
| `[INTEREST RATE]` | 8% (default for seller notes on standby; adjust if Block E specifies). |
| `[NOTE TERM]` | 60 months (default; adjust per Block E). |
| `[BALLOON/NO BALLOON]` | "no balloon" for fully amortized; otherwise state balloon terms. |
| `[STANDBY MONTHS]` | 12 months (default; adjust per Block E). |
| `[WORKING CAPITAL PEG]` | Block B working capital estimate (AR + inventory − AP). If unknown, state "to be finalized during due diligence." |
| `[EMD AMOUNT]` | 1–2% of the purchase price (standard for main street deals). Compute and state the dollar amount. |
| `[EXCLUSIVITY DAYS]` | 60 days (default; 90 for complex or larger deals). |
| `[DD DAYS]` | 30 days (default; 45 for complex businesses with environmental or multi-site operations). |
| `[CLOSE TARGET DAYS]` | 75 days from LOI date (default). |
| `[GOVERNING STATE]` | The state where the business is located (from the listing). |

### Step 4 — Fill the Template

Produce the LOI by substituting the placeholders in `templates/loi-template.md` with the extracted values. Preserve all section structure and headings. Do not omit sections.

### Step 5 — Add a Header Note

Prepend a short header (as a blockquote at the top, before the LOI body):

```markdown
> **Draft Letter of Intent — Non-Binding.** Generated by BizBuyBot from the evaluation report for deal {NNN}. This is a draft for review by the buyer and their counsel. Do not submit without legal review. Source evaluation: `reports/{NNN}-{slug}-{date}.md`.
```

### Step 6 — Write the Output

Write the filled LOI to `reports/{NNN}-loi.md` (note: no slug or date in this filename — just the ID, per `DATA_CONTRACT.md`).

### Step 7 — Update the Deal Status (optional, recommended)

If the buyer intends to submit this LOI, transition the deal status:

```bash
node set-status.mjs {NNN} LOI_Submitted --reason="LOI drafted and ready for submission"
```

This requires the current status to be `Under_Review` (or a state whose `next` includes `LOI_Submitted`). If the current status does not allow this transition, skip the status update and note the required prior state in the terminal summary.

### Step 8 — Terminal Summary

Print:

```
BizBuyBot LOI Draft — {NNN}
  Business:       {name}
  Purchase Price:  {purchase price}  (Block E anchor valuation)
  Cash at Close:   {cash at close}
  Seller Note:     {seller note}  (standby {standby months} months)
  EMD:             {emd amount}
  Exclusivity:     {exclusivity days} days
  Output:          reports/{NNN}-loi.md
  Next: Review with counsel, then submit. Run `node set-status.mjs {NNN} LOI_Submitted --reason="..."` after submission.
```

---

## Notes

- The LOI is non-binding except for confidentiality and exclusivity sections. State this clearly in the document (the template already does).
- Always use the **target anchor valuation** from Block E as the purchase price, not the asking price, unless Block E is silent.
- If the evaluation report did not produce a Block E capital stack, halt with an error and instruct the user to run `modes/evaluate.md` first.
