# bizbuybot export

$ARGUMENTS

Load the bizbuybot skill and run the `export` subcommand:

```javascript
skill({ name: "bizbuybot" })
```

Run `node export-pipeline.mjs --format=csv|json` from the project root. $ARGUMENTS selects the format.
